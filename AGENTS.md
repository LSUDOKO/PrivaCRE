# PrivaCRE

Bringing Real-World Credit Scoring to DeFi Without Compromising Privacy

Package manager: npm.

## Commands

- dev: `npm run dev`
- build: `npm run build`
- lint: `npm run lint`

## Layout

- `PrivaCRE/`
- `artifacts/`
- `contracts/`
- `cre-templates-main/`
- `cre-workflow/`
- `docs/`
- `scripts/`
- `src/`

## Rules

- Never commit secrets or `.env` files.
